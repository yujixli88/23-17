# 23-17

FastAPI-приложение с игровыми страницами, регистрацией пользователей и SQLite-базой `game.db`.

## Запуск

Выберите workflow **FastAPI API** в меню рядом с кнопкой Run. Для запуска из Shell:

```bash
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## Страницы и API

- `GET /` — главное меню
- `GET /play` — игровая страница
- `POST /api/register` — регистрация пользователя
- `POST /api/login` — проверка почты и пароля зарегистрированного пользователя
- `/docs` — интерактивная документация FastAPI

Пароли сохраняются в SQLite (`game.db`) только в виде PBKDF2-хешей. На форме регистрации можно сгенерировать пароль, который соответствует требованиям.

## Важно перед публикацией

Регистрация проверяет пароль на сервере и хранит его PBKDF2-хеш, а не исходное значение. Вход проверяет пароль по сохранённому хешу и возвращает одинаковую ошибку при неверной почте или пароле.
